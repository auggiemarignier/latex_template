# Journal

A dump of journal-specific class, style and bibstyle files.

## Sources

- `agujournal2025` - [https://github.com/AGU-Publications/agujournal2025-latex-template](https://github.com/AGU-Publications/agujournal2025-latex-template)
- `gji-latex` - [https://academic.oup.com/gji/pages/general_instructions#LaTeX](https://academic.oup.com/gji/pages/general_instructions#LaTeX)
    > To get this template to work you'll need to modify `preamble.tex`.
    > Remove the `parksip` and `geometry` packages.
    > Add the following if you want to use `siunitx`:
    >
    > ```
    > \let\tablenum\relax
    > \usepackage{siunitx}
    > \usepackage{gji-siunitx-patch}
    > ```
    >
- `seismica_submission_latex` - [https://github.com/WeAreSeismica/templates](https://github.com/WeAreSeismica/templates)
- [`oxbeamer`] - Custom class for `beamer` presentations.  Modified from OXES intranet template.
